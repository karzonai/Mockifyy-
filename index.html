Privacy Policy
Simple and transparent.

1. Introduction

Mockifyy is designed to help students practice multiple-choice questions and take mock tests. This starter version stores demo account and progress information locally in the browser.

2. Information

The current demo may store your name, email, selected class, selected board and learning statistics in local browser storage. No real server account is created by this standalone file.

3. How information is used

  • To display your profile.
  • To remember your academic preferences.
  • To calculate practice and test statistics.
  • To keep the demo experience consistent between sessions.

4. Security

This standalone demo is not a production authentication system. Do not use real passwords in this demo. A production release should use a secure authentication provider such as Firebase Authentication and a properly secured database.

5. Future production version

Before public launch, Mockifyy should add server-side authentication, database security rules, proper consent, account deletion, secure question APIs and production privacy documentation.
